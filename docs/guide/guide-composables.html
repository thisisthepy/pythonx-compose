Writing composables컴포저블 작성하기

Screens are functions; widgets are Compose's own.화면은 함수이고, 위젯은 Compose 의 것입니다.

partial부분

Material 3 widgets have been rendered from Python in python-multiplatform's own tests (Text, Button, Card, ListItem, Badge, MaterialTheme, IconButton, Checkbox, Switch, TextField). This package does not yet re-export them under pythonx.compose.material3.

Material 3 위젯은 python-multiplatform 자체 테스트에서 파이썬으로 렌더링되었습니다 (Text, Button, Card, ListItem, Badge, MaterialTheme, IconButton, Checkbox, Switch, TextField). 이 패키지는 아직 pythonx.compose.material3 아래로 재노출하지 않습니다.

Write a screen화면 하나 쓰기

from pythonx.compose.runtime import Composable
from pythonx.compose.material3 import Text, Card

@Composable
def Profile(name: str):
    Card(content=lambda: Text(f"Hello, {name}"))

A screen is a plain function. @Composable marks it; it does not wrap it. Content slots take a lambda.

화면은 평범한 함수입니다. @Composable 은 표시만 하고 감싸지 않습니다. content 슬롯은 람다를 받습니다.
