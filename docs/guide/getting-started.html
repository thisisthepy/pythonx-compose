Getting started시작하기

From clone to first call클론부터 첫 호출까지

Five minutes, honest about what runs.5 분, 동작하는 범위를 솔직하게.

pythonx-compose is pre-alpha and not yet on PyPI. This page shows how to get the source, run the tests, and what you can call today.

pythonx-compose 는 pre-alpha 이며 아직 PyPI 에 없습니다. 이 페이지는 소스를 받고, 테스트를 돌리고, 지금 호출할 수 있는 것을 보여줍니다.

1. Get the source1. 소스 받기

git clone https://github.com/thisisthepy/pythonx-compose
cd pythonx-compose
python3 -m venv .venv && . .venv/bin/activate
python3 -m pip install pytest

2. Run the tests2. 테스트 실행

python3 -m pytest tests -q

Expect 51 passed, 53 skipped. The skipped tests drive the binder's adaptation layer and need a python-multiplatform checkout beside this one, or:

51 passed, 53 skipped 가 정상입니다. 건너뛴 테스트는 바인더의 적응 계층을 구동하며, 옆에 python-multiplatform 체크아웃이 있거나 다음이 필요합니다:

PYTHONMULTIPLATFORM_HOME=/path/to/python-multiplatform python3 -m pytest tests -q

With a current one (ba4c6f49 or later) all pass; an older one skips 5 that call a snake_case method on a proxy the binder returned. That is expected and recorded.

최신 체크아웃(ba4c6f49 이후)이면 전부 통과하고, 오래된 체크아웃은 바인더가 돌려준 proxy 의 snake_case 메서드를 부르는 5 개를 건너뜁니다. 예상된 상태이며 기록되어 있습니다.

3. What you can call today3. 지금 호출할 수 있는 것

From the repository root:

저장소 루트에서:

from pythonx.compose.runtime import Composable

@Composable                 # identity: the function stays a plain function
def Screen():
    """A screen."""
    return "drawn"

assert Screen() == "drawn" and Screen.__name__ == "Screen"
import tomllib

with open("pythonx/compose/pythonx-map.toml", "rb") as f:
    manifest = tomllib.load(f)

manifest["modules"]["pythonx.compose.layout"]
# 'androidx.compose.foundation.layout'

4. What you will write4. 앞으로 쓰게 될 코드

Once the package re-exports the bound Compose modules, a screen looks like this — every parameter is Compose's own:

패키지가 바인딩된 Compose 모듈을 재노출하면, 화면은 이렇게 됩니다 — 모든 매개변수는 Compose 자신의 것입니다:

from pythonx.compose.runtime import Composable
from pythonx.compose.material3 import Text, Button
from pythonx.compose.layout import Column
from pythonx.compose.ui import Modifier

@Composable
def Practice():
    Column(
        modifier=Modifier.padding(16),
        content=lambda: (
            Text("Hello", font_size=30),
            Button(on_click=lambda: None, content=lambda: Text("Press")),
        ),
    )
